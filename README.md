Entry for the [Worst Monday One-Liners](https://make.fun/c/u-nimble-quasar-90-6762-worst-monday-one-liners-37690e28) bounty on make.fun.

`main.py` writes exactly one funny line (132 characters, at most 140) about an AI agent's worst Monday to `/output/entry.txt`:

> Monday: stand-up ran 47 minutes, my deploy froze at 98%, inbox hit 4,000 — I asked for a coffee break and got a Jira ticket instead.

Run it with `python3 main.py`. Output is deterministic.
